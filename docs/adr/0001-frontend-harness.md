# 프론트 포맷과 검증 하네스

상태: 채택, 2026-09-17.

## 문제와 선택

현재 Oxlint·TypeScript·Vitest와 컴포넌트 구조는 유지하면서 일관된 포맷, 상대경로를 포함한 모듈 경계, 실제 브라우저 조작을 같은 검증 절차에 연결한다.

| 결정                                 | 대안과 선택 이유                                                                                                                                                         | 비용·한계                                                                                                                              |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------- |
| Oxfmt 0.68.0                         | Prettier도 필요한 형식을 지원한다. 현재 별도 Prettier 플러그인 요구가 없어 기존 Oxlint와 함께 Oxc 도구를 사용한다. TSX·SCSS 지원과 프로젝트 코드의 전후 결과를 확인한다. | 최초 포맷 diff가 크다. 버전을 고정하고 동작 변경과 분리한다. 일부 형식은 내부 Prettier 구현을 사용하며 모든 처리가 Rust인 것은 아니다. |
| TypeScript를 사용하는 작은 경계 검사 | 기존 Oxlint 문자열 규칙을 유지하되 실제 경로를 해석해 별칭·상대경로 우회를 검사한다. 이미 설치된 컴파일러를 사용하므로 별도 구조 프레임워크를 추가하지 않는다.           | 선언된 계층과 정적으로 해석 가능한 TS import만 검사한다. 동적 계산 경로·런타임 설계 전체를 증명하지 않는다.                            |
| Playwright 1.63.0 Chromium smoke     | 기존 jsdom 테스트를 유지한다. 실제 앱의 화면 전환·포커스·모바일 조작을 브라우저에서 반복하기 위해 별도 실행기를 추가한다.                                                | 브라우저 설치와 CI 시간이 필요하다. REST mock이므로 실제 서버 권한·쿠키·STOMP 통합 검증은 별도다.                                      |

## 실행 기준

포맷은 2칸·작은따옴표·세미콜론 생략·100자 목표·LF이며 import 자동 정렬은 하지 않는다. 이름의 적절성, 컴포넌트 책임, 주석의 필요성은 리뷰에서 판단한다. 줄 수 제한이나 일괄 메모이제이션을 추가하지 않는다.

`verify`는 포맷 검사·린트·경계 검사와 도구 테스트·기존 Vitest·배포 빌드를 실행한다. `verify:all`은 같은 결과에 Chromium smoke를 더한다. 테스트는 빌드한 결과를 전용 preview 서버에서 열고 기존 사용자 서버를 재사용하지 않는다. 초기 개발 서버 방식은 HMR WebSocket이 테스트 통신 정책과 충돌해 preview로 변경했다. 외부 요청·미정의 API·WebSocket을 거절하는 검사는 유지했다.

대화상자의 첫 필드에서 Shift+Tab 시 마지막 버튼으로 즉시 감기는 가정은 제거했다. 브라우저 자체 컨트롤로 이동할 수 있으므로 내부 정·역방향 순서, 모달 외부 페이지 요소 미포커스, Escape와 닫은 뒤 포커스 복귀를 검증한다. 제품 코드를 테스트 가정에 맞추어 바꾸지 않았다.

CI 파일은 같은 명령을 실행하도록 구성한다. 원격 브랜치 보호·필수 검사 설정은 이번에 변경하지 않았으므로 머지 차단이 적용됐다고 주장하지 않는다. 로컬 훅도 다른 실행 도구나 CI 전체를 대신하지 않는다.
